# 📚 Word Trainer Pro — مدرّب الكلمات

تطبيق ويب (HTML/CSS/JS بدون مكتبات) لحفظ الكلمات الإنجليزي.

## المميزات
- **نظام التكرار المتباعد (SRS / Leitner)**: كل كلمة ليها مستوى وموعد مراجعة
- **11 طريقة تدريب**: مراجعة ذكية، اختار الكلمة، اختار المعنى، إملاء، استماع، أكمل الجملة، ترتيب حروف، تطابق، هانج مان، تحدي السرعة، نطق (ميكروفون)
- لوحة تقدم: XP ومستويات وأيام متتالية وهدف يومي
- **إكمال تلقائي**: المعنى بالعربي (MyMemory) + التعريف والمثال (dictionaryapi.dev) + صور (Wikipedia)
- إيموجي كصورة لأكتر من 100 كلمة شائعة
- إضافة كلمات بالكتابة أو رفع ملف txt/json، ونسخة احتياطية JSON
- وضع فاتح/داكن تلقائي، ومتجاوب مع الموبايل
- البيانات محفوظة في المتصفح (localStorage)

## صيغة الكلمات
```
apple - تفاحة | I eat an apple every day
book - كتاب
beautiful
```

## النشر على GitHub Pages
1. ارفع الملفات على Repository جديد.
2. Settings → Pages → Deploy from a branch → `main` / `(root)`.
3. الرابط: `https://USERNAME.github.io/REPO-NAME/`

> الإكمال التلقائي والصور والنطق بالميكروفون محتاجين إنترنت، والميكروفون بيشتغل أحسن على Chrome.
